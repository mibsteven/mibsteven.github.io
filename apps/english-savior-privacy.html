英語救星 隱私權政策

iOS · iPadOS · visionOS
2026-10-15 · Yu-Hsiang Chang

適用版本

本政策區分 iOS 1.42、visionOS 1.3 的 build 7 起版本，以及仍可能使用外部文字服務的較早版本。新版目前為更新準備版本；請以裝置上安裝的版本為準。

1. 新版不蒐集資料

Build 7 起只使用系統提供的文字模型與生圖介面，不再提供 Gemini、Groq 或自備 API 金鑰（BYOK）。開發者不接收你的學習文字、音訊、圖片、識別資料、用量或診斷紀錄。本 App 沒有開發者自建後端、廣告、追蹤或第三方分析／當機回報 SDK，也不需要註冊開發者帳戶。依目前實作與 App Store 的定義，新版符合「Data Not Collected／不蒐集資料」的申報方向；這不表示所有系統功能都離線運作。

2. 系統文字模型

練習回饋、字典解釋、故事與插畫描述使用 Foundation Models 框架的 SystemLanguageModel.default 裝置端模型。文字推論在裝置上進行，需支援的裝置、語言、系統設定與已下載的模型。模型不可用時會顯示說明，不會轉送至外部文字服務。介面翻譯不等於模型支援該語言。

3. 系統生圖

你點選「產生插圖」後，App 透過 Image Playground 框架開啟系統介面，提供由故事整理的簡短圖片描述。你可以調整描述、接受圖片或取消。iOS 27 與 visionOS 27 的系統生圖使用 Apple 的 Private Cloud Compute，需要網路連線；較早支援版本依該版本的系統功能處理。開發者沒有生圖伺服器或轉送服務。App 不啟用第三方服務商的圖片風格或人物個人化，也不提供來源照片。取消不會刪除故事或既有插畫。

4. 語音與系統服務

iOS 的選用語音輸入會請求麥克風及語音辨識權限，透過系統 Speech 框架把聲音轉為練習文字，依裝置與系統狀態可能使用線上語音辨識。辨識後的文字只交給系統文字模型。朗讀使用系統文字轉語音。開發者不接收音訊，也不另行保存原始錄音。系統服務的資料處理依系統說明與你的設定；依 Apple 的 App Store 隱私指引，Apple 自行蒐集的資料不由開發者代為申報。

5. 本地資料、備份與刪除

生字、練習紀錄、收藏故事與插畫保存在 App 的本地容器，可在 App 內刪除。移除 App 通常也會移除本地資料；系統備份是否包含這些資料，取決於你的系統設定。產生的內容可能有誤，請依學習需求核對。

6. 升級與舊版外部服務

升級至 build 7 會保留原有生字、練習紀錄、故事、圖片及已保存的閱讀作答，只移除退休的服務商設定與本 App 儲存的兩個 API 金鑰項目。裝置受保護而無法刪除金鑰時，之後啟動會重試；新版不會讀取或傳送金鑰。這不會撤銷服務商帳戶中的金鑰，也不能刪除舊版已傳送的資料。

較早版本的資料傳送

仍使用較早版本並啟用 BYOK 時，字典的單字及上下文、練習輸入、故事生字與主題、語言偏好及任務指示會由裝置直接傳送至選定的 Gemini 或 Groq，以金鑰驗證服務帳戶；不經開發者伺服器。服務商可能保留內容、帳戶／專案識別、用量與診斷資料。Gemini 的未付費內容可能用於產品改進；付費及免費服務另有安全留存規則。Groq 可能因安全或可靠性保留內容，並保留用量中繼資料。相關資料可能與服務帳戶連結，受服務商政策、年齡及地區條款約束。舊版可關閉傳送同意或移除金鑰以停止新請求；過往資料與金鑰撤銷請向服務商管理。新版不蒐集資料的描述不套用至這些舊版 BYOK 傳送。

7. 聯絡與政策更新

如有隱私問題，請來信 mibsteven.chang@gmail.com。功能或資料處理變更時會更新本頁。框架與服務名稱僅用於辨識技術及資料接收方，不表示贊助、背書或合作關係。

EnglishSaver Privacy Policy

iOS · iPadOS · visionOS
2026-10-15 · Yu-Hsiang Chang

Version scope

This policy distinguishes iOS 1.42 and visionOS 1.3 starting with build 7 from earlier versions that may still use external text services. The new build is currently being prepared as an update; refer to the version installed on your device.

1. No data collection in the new build

Starting with build 7, the app uses only system text models and the system image interface. Gemini, Groq and bring-your-own API keys (BYOK) are no longer offered. The developer receives no learning text, audio, images, identifiers, usage or diagnostic records. There is no developer backend, advertising, tracking, third-party analytics or crash-reporting SDK, and no developer account to create. Based on the implemented data flow and App Store definitions, the new build qualifies for a Data Not Collected declaration. This is not a claim that every system feature works offline.

2. System text model

Practice feedback, dictionary explanations, stories and illustration briefs use the Foundation Models framework with the on-device SystemLanguageModel.default model. Text inference runs on your device and requires a supported device, language, system settings and downloaded model. When unavailable, the app explains the limitation and does not forward requests to an external text service. Interface translations do not guarantee model language support.

3. System images

Choosing Create Illustration opens the Image Playground system interface with a short description derived from the story. You can edit the description, accept an image or cancel. On iOS 27 and visionOS 27, system image generation uses Apple’s Private Cloud Compute and needs internet. Earlier supported versions use their system image service. The developer operates no image server or relay. The app does not enable third-party image styles or person personalization and supplies no source photo. Cancelling preserves the story and any previous illustration.

4. Speech and system services

Optional iOS dictation requests microphone and speech-recognition permission. The system Speech framework transcribes microphone audio and may use online recognition depending on device and system availability. Transcribed text is passed only to the system text model. Read-aloud uses system speech synthesis. The developer receives no audio and does not separately save raw recordings. System processing follows system disclosures and your settings. Apple’s App Store privacy guidance states developers are not responsible for declaring data collected by Apple itself.

5. Local storage, backups and deletion

Vocabulary, practice records, collected stories and illustrations are saved in the app’s local container and can be deleted within the app. Removing the app normally removes its local data; system backups may include that data depending on your settings. Generated content may contain mistakes and should be checked for your learning needs.

6. Upgrades and earlier external services

Upgrading to build 7 preserves existing vocabulary, practice records, stories, images and saved reading answers. Only retired provider preferences and the two app-owned API key items are removed. If protected Keychain data is temporarily unavailable, removal is retried on later launches; the new build does not read or transmit those keys. This does not revoke keys in the provider account or delete data already sent by an older version.

Data transmission in earlier versions

If you still use an earlier version with BYOK enabled, dictionary words/context, practice input, story vocabulary/theme, language preferences and task instructions go directly from the device to the selected Gemini or Groq service, authenticated with your key, without a developer server. Providers may retain content, account/project identifiers, usage and diagnostic data. Gemini unpaid content may be used for product improvement; paid and unpaid services also have safety-retention rules. Groq may retain content for security or reliability and retains usage metadata. Records may be linked to your service account and are subject to provider privacy, age and regional terms. Older versions let you withdraw transmission consent or remove a key to stop new requests. Manage previously sent data and key revocation with the provider. The new build’s no-collection description does not apply to these older BYOK transmissions.

7. Contact and policy updates

For privacy questions, contact mibsteven.chang@gmail.com. This page is updated when features or processing change. Framework and service names identify technologies and recipients and do not imply sponsorship, endorsement or partnership.
